## 项目放 GitHub，话说在博客

项目在GitHub 上。但如今阅读代码是一项繁重的劳动。

关于为什么做它、中间卡了多久、最后怎么绕过去，代码里找答案很费劲。

所以搭了这个博客，记录下这些内容有两个目的：

1. **留个底**：人的大脑是一个会缓慢消磁的磁铁，过仨月回头看，当时的坑基本全忘了，于是要时常复习看一看。
2. **逼自己把话讲清楚**：如果一个东西无法用自然语言讲明白，那多半是我还没搞懂。于是倒逼自己写出来，用以反哺学习。

## 为什么自己搭，不用现成平台

| 方案 | 成本 | 数据在哪 | 结论 |
| --- | --- | --- | --- |
| 博客园 / CSDN | 0 元 | 在平台上，搬家麻烦 | 备选 |
| VitePress + GitHub Pages | 0 元 | Markdown 文件全在自己手里 | **选它** |

选 VitePress 的理由有三条：

1. 没有服务器，没有数据库，很难被玩坏
2. 文章是 Markdown 文件，push 上去发布方便
3. 如果想迁移，整个文件夹拷走就行
